# 6. DESIGN PRINCIPLES

Judge every design decision against these principles.

## Content before decoration

- My name, professional identity and achievements come first.
- A visitor should understand who I am, what I do and what opportunities I am interested in within five seconds.
- No unnecessary text explaining the website itself.
- No decorative elements without a purpose.

## Clear hierarchy

Every screen should quickly answer:

1. Where am I?
2. What information is here?
3. What should I do next?

## Layout

- Use spacing and alignment before introducing borders or boxes.
- Avoid cards inside cards.
- Avoid excessive outlines.
- No thick coloured stripes on the side of cards.
- Keep cards flat and clean.
- Use shadows only when something genuinely needs to appear elevated.
- Use no more than two main background tones.

## Typography

- Use no more than two font families.
- Use a clear hierarchy between headings, body text and supporting information.
- Keep paragraphs readable, approximately 65–75 characters per line.
- Maintain consistent spacing.
- Avoid excessively small text.

## Colour

- Define colours as CSS variables.
- Use neutral backgrounds and text.
- Choose one primary accent colour.
- Use the accent consistently for links and important actions.
- Maintain strong contrast and readability.

## Interaction

- Hover effects should be subtle.
- Buttons must not jump, grow or tilt.
- Navigation must work.
- Contact information must be accessible.
- All buttons must have meaningful labels.
- The website must be usable on mobile and with a keyboard.
- Include visible keyboard focus states.
- Minimum touch target: 44px.

## HTML requirements

- Link style.css inside the HTML head.
- Use proper headings, sections, navigation, links, buttons and accessible labels.
- Every navigation link and button must work using standard HTML functionality.
- Use mailto links for email contact.
- Use ordinary anchor links for navigation between sections.

## CSS requirements

- All styling must be written in style.css.
- Define colours inside :root using CSS variables.
- Use element selectors such as body, h1 and a.
- Use class selectors such as .card and .nav-link.
- Use ID selectors such as #hero and #resume.
- Use Flexbox and CSS Grid for layouts.
- Use CSS for responsive behaviour.
- Use CSS for hover and focus states.

- No external icon libraries.
- No external scripts.
- No frameworks or libraries.
- Avoid unnecessary external assets.

## Responsive design

Include:

- One @media rule for screens narrower than 700px.
- One @media print rule.
- If transitions are used, include @media (prefers-reduced-motion: reduce).

The website must work properly on desktop, tablet and mobile.

The website must include a dedicated section with id="resume".

It should look like a proper one-page professional resume printed on a white sheet.

## Print requirements

The @media print rule must:

- Hide everything except #resume.
- Use black text on a white background.
- Fit the resume onto one A4 page.
- Remove unnecessary website navigation and screen-only elements.
- Avoid clipping or unreadably small text.

- Use lowercase filenames without spaces.
- Every image must have descriptive alt text.
- Don't use unnecessary stock photographs or random icons.

## Final technical verification

Before delivering the website, verify that:

1. It contains exactly two code files.
2. Every website feature is implemented using HTML or CSS.
3. There is absolutely no JavaScript.
